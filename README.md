# Apple Financial Dashboard

An executive financial intelligence dashboard for Apple Inc. displaying key performance metrics, revenue trends, net income, and gross profit margins.

## Features
- Executive Overview & Metrics (Revenue, Net Income, Gross Profit Margin)
- Interactive Performance Charts & Multi-Year Trends
- Financial Statement Explorer & Ratio Analysis
- Forecasting Tools

2. DATA ENGINE SCHEMA (JSON Core Dataset)
------------------------------------------------------------------------
{
  "company": "Apple Inc. (AAPL)",
  "reportingPeriod": "Form 10-K (Annual)",
  "units": "Millions of USD",
  "historicalData": [
    {
      "fiscalYear": "2025",
      "totalNetSales": 416181,
      "totalCostOfSales": 246022,
      "operatingExpenses": 34550,
      "netIncome": 95201
    }
  ]
}


3. CORE ACCOUNTING AUTOMATED FORMULAS
------------------------------------------------------------------------
* Gross Profit Margin Formula:
  = ((TotalNetSales - TotalCostOfSales) / TotalNetSales) * 100

* Net Profit Margin Formula:
  = (NetIncome / TotalNetSales) * 100
